# 通知拦截器 NotificationBlocker

用无障碍服务（AccessibilityService）自动关掉「**正在运行的服务**」弹窗的 Android 小工具：弹窗一出现就自动按返回键，让你没法从后台把指定应用（比如番茄锁）停掉。

## 功能

- **只拦截弹窗**：检测到「正在运行的服务」弹窗 → 立即返回关闭，重试 20 次 × 80ms
- **不拦截下拉通知栏**：通知栏、控制中心保持系统原生行为，随便用
- **总开关**：一键开/关拦截
- **时间段调度**：可添加多个时间段（滚轮式时间选择器），只在设定时间内拦截；不设时间段 = 全天生效
- 系统更新本应用后，无障碍服务会自动重新连接

## 安装

到 [Releases](../../releases) 下载 `NotificationBlocker-v1.5.apk` 安装，或直接用仓库中的构建产物。

安装后：

1. 打开 App → 点「去开启无障碍」→ 找到「通知拦截器」→ 开启
2. 回到 App，打开顶部开关（需要拦截时才开）
3. 需要限时拦截的话，点「添加时间段」

## 实现原理

```
无障碍事件（TYPE_WINDOW_STATE_CHANGED / TYPE_WINDOW_CONTENT_CHANGED）
        │
        ├─ 事件批量延迟设为 0ms，状态变化事件立即检测
        │   （抓空时补 60 / 120 / 200 / 300ms 四次快速复查）
        │
        ├─ 遍历 getWindows()：
        │   第一遍只比对窗口标题（近零开销）
        │   第二遍只对 systemui 窗口做文本搜索
        │   命中条件：标题含「正在运行的服务」
        │             或页面同时含「番茄锁」+「知道了」
        │
        └─ 命中 → 同步执行 GLOBAL_ACTION_BACK（全局返回）
                  随后 20×80ms 重试兜底
```

时间开关判断：`SharedPreferences`（`NotificationBlockerPrefs`）里的 `block_enabled` + `time_ranges`，服务每 30 秒重算一次，保证时间段到期自动停用。

## 已知限制

- 手指**按住**通知栏不放时，Android 会屏蔽所有全局关闭指令，必须松手才生效（系统级限制，无障碍服务无法绕过）——当前版本不拦通知栏，此条仅作记录
- 弹窗必须由系统发出「窗口状态变化」事件才会被发现，理论上响应延迟 ≈ 系统窗口动画 + 事件投递，实测在几十毫秒级

## 日志调试

过滤标签：

```bash
adb logcat -s NBService
```

会输出服务连接、事件类型、检测结果、发送返回键等信息。
